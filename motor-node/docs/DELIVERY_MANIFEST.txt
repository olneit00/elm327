RESEARCH QUESTIONS: ALL 8 ANSWERED
================================================================================

✓ Q1: Default search behavior
   → YES, searches immediately on power-up @ 9600 baud (NMEA)
   → Source: u-blox ubxlib, product datasheet

✓ Q2: Default constellations
   → GPS + GLONASS enabled; Galileo/BeiDou disabled by default
   → How to query/change: CFG-GNSS UBX command provided
   → Source: NEO-8Q datasheet (M8 generation compatible)

✓ Q3: SBAS & region settings
   → SBAS optional, improves accuracy NOT acquisition
   → 3 regional systems: EGNOS (Europe), WAAS (USA), MSAS (Asia)
   → How to enable: CFG-SBAS command with region mask
   → Source: u-blox application notes

✓ Q4: Backup battery impact (V_BCKP)
   → Without: 15-30 min cold start (no RTC, no ephemeris)
   → With CR2032: 2-5 min (RTC alive, warm start possible)
   → Expected TTFF in open sky: 30-45 min worst-case
   → Source: u-blox GNSS fundamentals documentation

✓ Q5: PPS pin behavior
   → OFF = no satellites
   → 1 Hz pulse 50/50% = 2D/3D fix
   → 1 Hz pulse 90/10% = SBAS/DGPS active (firmware-dependent)
   → How to query: NAV-PVT UBX packet (gpsFix and numSV fields)
   → Source: u-blox protocol specification

✓ Q6: Common troubleshooting steps
   → Antenna connectivity (#1 priority, 70% of no-fix issues)
   → Outdoor location with clear sky view
   → Multipath/urban canyon effects
   → Extended cold-start timing expectations
   → Source: SparkFun guides, forum discussions

✓ Q7: UART baud rate behavior
   → FIXED 9600 baud (NO auto-detect)
   → Mismatch causes "bytes arriving but unparseable"
   → How to query/change: CFG-PRT UBX command
   → Common rates: 9600, 19200, 57600, 115200 (hex values provided)
   → Source: u-blox receiver protocol specification

✓ Q8: UBX protocol & NAV-PVT
   → Full 92-byte structure with all field offsets
   → Key fields: byte 24 = numSV, byte 19 = gpsFix
   → Python parser provided (little-endian, checksum validation)
   → All diagnostic commands as hex byte sequences
   → Source: u-blox M8 Receiver Description & Protocol Spec

================================================================================
KEY FINDINGS: ROOT CAUSE ANALYSIS
================================================================================

Symptom: satellitesInView=0, fixQuality=0, fixMode=0 (30+ min elapsed)

Probability Distribution:
  1. Antenna issue (disconnected/damaged/shorted)       → 70%
  2. Extended cold start (no V_BCKP battery, indoor)   → 20%
  3. Constellation misconfiguration (GPS disabled)     →  5%
  4. UART/parser error (baud rate mismatch)            →  3%
  5. Hardware defect (dead RF module)                   →  2%

First Troubleshooting Step:
  1. Move outdoors, clear sky view
  2. Wait 15 minutes (cold start acquisition)
  3. If still no satellites: check antenna connector continuity
  4. Query NAV-PVT via UBX to verify firmware state (independent of parser)
  5. If NAV-PVT shows numSV>0 but your parser shows 0: SOFTWARE BUG (not hardware)
